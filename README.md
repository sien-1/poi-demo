# POI 数字疗法框架 · 演示入口

本目录把两个前端原型放在一起，方便老师或评审从同一个入口查看：

- `web/`：网页端（患者 + 医生视角）
- `app/`：患者端手机 App 界面
- `survey.html`：随访问卷选择入口

问卷入口中的 11 个量表已经按类别列出。将 `survey.js` 中每一项的 `url` 字段替换为对应的腾讯文档问卷链接后，点击“开始填写”即可跳转。

## 运行

1. VS Code 打开本文件夹
2. 安装 Live Server 扩展
3. 右键 `index.html` → Open with Live Server
4. 在入口页分别打开网页端和手机端

所有页面均为功能原型，数据为模拟数据，按钮为演示占位，不包含真实后端、量表计分、风险模型或医疗建议。
