# POI 数字随访管理平台 · 演示入口

本目录把两个前端原型放在一起，方便老师或评审从同一个入口查看：

- `v021/`：V0.2.1 患者三模块、医生四模块联动演示
- `web/`：旧版 V0.1 网页端（患者 + 医生视角）
- `app/`：旧版 V0.1 患者端手机 App 界面
- `survey.html`：现有随访问卷及研究完整版入口

V0.2.1 使用同一浏览器中的 `localStorage` 模拟患者端与医生端的数据联动。所有数据均为演示数据，不是真实医疗系统。

## 运行

1. VS Code 打开本文件夹
2. 安装 Live Server 扩展
3. 右键 `index.html` → Open with Live Server
4. 在入口页分别打开网页端和手机端

所有页面均为功能原型，数据为模拟数据，按钮为演示占位，不包含真实后端、量表计分、风险模型或医疗建议。
