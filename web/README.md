# POI 数字疗法框架 · 前端功能原型

面向早发性卵巢功能不全（POI）全生命周期管理的数字疗法界面原型。

> 本版本仅用于展示模块结构与界面形态，所有患者数据均为模拟数据，不包含真实个人信息，不构成医疗建议。功能按钮为演示占位，尚未连接后端、模型或真实量表计分。

## 模块

- 总览：全生命周期链路、风险状态、今日待办
- 风险评估：基础信息、关键指标与模拟风险分层结果
- 随访复诊：复诊计划、随访任务与逾期状态
- 健康教育：分层教育内容、学习进度与打卡
- 健康监测：睡眠、压力、情绪、心理量表及异常提示
- 用药与补剂：处方用药、补剂、依从性记录与医生审核提示
- 医生工作台：临床红线、方案审核、失访随访待办

## 运行

1. 用 VS Code 打开本文件夹
2. 安装 Live Server 扩展
3. 右键 `index.html` → **Open with Live Server**

纯静态 HTML/CSS/JavaScript，无后端、无构建步骤。

## 范围说明

- 本版本只做前端空壳，不包含真实数据采集、算法预测、量表计分、账号、数据库或消息推送
- 所有临床规则、字段与阈值需由团队和指导老师确认后再实现
- 补剂不是药物，不能替代医生处方；用药与补剂均需医生审核
