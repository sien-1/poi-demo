# POI 数字随访管理平台 V0.2.1

本目录是按照《POI 全生命周期数字随访管理平台产品说明书（V0.2 概念设计稿）》重构的前端闭环演示。

## 页面范围

### 患者端：三个一级模块

- 上传医嘱：模拟识别、字段核对、提交审核和电子医嘱生效。
- 干预日历：医生审核后自动生成任务，支持任务完成并更新状态。
- 病例夹与消息：查看电子医嘱、原始资料入口及状态消息。

入口：`app/index.html`

### 医生端：四个一级模块

- 随访患者目录：患者检索、单患者双视图和医嘱审核。
- 数字医嘱套：查看模板任务并应用到演示患者。
- 随访数据大盘：队列指标、随访深度和年龄结构。
- 业务处理大盘：待审核、本周/下周复诊、逾期与失访事项。

入口：`doctor/index.html`

## 演示主线

1. 在患者端点击“使用演示医嘱”。
2. 等待模拟识别完成后核对字段并提交。
3. 打开医生端，审核医嘱并下发数字医嘱套。
4. 返回患者端，在干预日历中完成任务。
5. 医生端任务执行情况随状态更新。

患者端与医生端需在**同一浏览器、同一站点来源**下打开，才能共享 `localStorage` 中的模拟状态。手机和电脑之间不会自动同步。

## 演示边界

- 仅使用一位模拟患者 P001。
- 不接入真实 OCR、账号、数据库、消息推送或风险预测模型。
- 问卷入口沿用项目根目录下的 `survey.html`，本版本不修改问卷内容。
- 不保存真实患者信息，不构成诊断或治疗建议。
- 页面提供“重置演示数据”，用于恢复初始状态。

## 运行

使用 VS Code Live Server 打开项目根目录，访问：

- `/v021/`：V0.2.1 总入口
- `/v021/app/`：患者端
- `/v021/doctor/`：医生端
