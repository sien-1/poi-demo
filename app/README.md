# POI 数字疗法 · 患者端 App 原型

面向早发性卵巢功能不全（POI）患者的移动端界面原型，与桌面端医生/管理端框架配套。

> 本版本仅用于展示 App 的信息结构与页面形态。所有患者数据、评分、风险概率均为模拟数据；按钮为演示占位，不连接真实后端、量表计分或风险模型，不构成医疗建议。

## 页面

- 首页：风险状态、今日待办、快捷入口、下次复诊
- 风险评估：基础指标填写与模拟风险分层
- 随访复诊：复诊计划与随访任务
- 健康教育：分层课程与学习进度
- 健康监测：睡眠、压力、情绪、心理量表与异常提示
- 用药与补剂：处方用药、补剂、依从性记录

## 运行

1. 用 VS Code 打开本文件夹
2. 安装 Live Server 扩展
3. 右键 `index.html` → **Open with Live Server**

桌面浏览器中会显示为手机外框；手机浏览器中会铺满屏幕。

## 范围说明

- 仅前端空壳，无真实数据采集、账号、消息推送或算法预测
- 量表名称、计分与阈值需临床团队确认后再实现
- 补剂不作为药物或治疗手段，所有用药与补剂方案需医生审核
