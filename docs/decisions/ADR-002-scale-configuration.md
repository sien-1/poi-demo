# ADR-002：患者与医生端量表配置

- 日期：2026-11-17
- 状态：Accepted

## 背景

患者问卷需要保持操作简洁，医生需要看到专业量表名称、版本和记录。部分量表需要由医生或研究人员施测。

## 决定

- Kupperman统一使用13项版本，删除11项入口。
- CMSS从量表目录和患者完整问卷中删除。
- MMSE、MoCA不进入患者问卷。
- MMSE、MoCA仅保留于医生端患者档案。
- 患者完整问卷当前包含41个编号条目。
- 保留原始答案、量表版本和计分规则的设计要求。

## 后果

- 更新量表时须同步修改目录、完整问卷、医生端入口和缓存版本。
- 每次量表调整后必须运行项目验证脚本。
- 量表授权、中文版本和施测资质仍需临床团队确认。
