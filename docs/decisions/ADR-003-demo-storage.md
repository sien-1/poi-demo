# ADR-003：演示阶段使用 localStorage

- 日期：2026-11-17
- 状态：Accepted

## 背景

当前阶段需要验证患者端和医生端的信息架构与操作闭环，尚未建设后端和真实数据权限。

## 决定

- 当前演示使用浏览器 `localStorage` 保存一位模拟患者的医嘱、任务和消息。
- 患者端与医生端必须在同一浏览器、同一站点来源运行。
- `localStorage` 不用于真实患者数据。

## 后果

- 手机与电脑之间不会同步。
- 清除浏览器存储会重置演示状态。
- 进入真实数据阶段前必须替换为后端数据库、身份认证、权限和审计。
- 当前实现不能被描述为真实医疗系统。
