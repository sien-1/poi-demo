# ADR-004：2027年大创申报赛道选择

- 日期：2026-11-17
- 状态：Accepted

## 背景

团队曾评估创业类产业特区子计划，并制作了对应PPT大纲。产业特区要求正式企业横向课题、企业命题、参与意向函和明确的产业交付目标，相关条件尚未最终落实。

## 决定

- 当前按照四川大学2027年度大创创新类项目准备材料。
- 创业类产业特区PPT大纲仅作为备选。
- 技术平台继续按照临床随访和研究验证逻辑建设。

## 后果

- 当前申报书使用创新类模板。
- 创业商业计划、财务预测和企业横向课题材料不再作为主提交材料。
- 若后续赛道再次变化，应新增ADR，不直接覆盖本决定。

## 证据

- 四川大学教务处2027年度大创申报通知
- 团队讨论记录
- `docs/evidence/2026-11-17-baseline.md`
