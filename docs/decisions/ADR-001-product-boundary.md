# ADR-001：POI数字随访平台的产品与医疗边界

- 日期：2026-11-17
- 状态：Accepted

## 背景

项目面向POI患者的长期随访和管理。平台连接医嘱、任务、问卷、复诊和健康教育，但不能替代医生完成诊断、处方和药物调整。

## 决定

- 平台定位为医生主导的数字随访工具。
- 患者端只呈现可执行任务和中性问卷入口。
- 医生端负责医嘱审核、任务下发、异常处理和随访管理。
- 模型和健康教育输出只作为辅助信息，须经医生复核。
- 平台不自动诊断，不自动开具或调整药物处方。

## 后果

- 所有任务必须保留来源、状态、操作者和时间。
- 任务完成率与临床结局分开采集和分析。
- 真实患者使用前必须完成伦理、隐私、安全和权限审查。
